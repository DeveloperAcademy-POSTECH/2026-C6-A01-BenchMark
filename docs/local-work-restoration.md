# develop 이후 로컬 변경 복원 — 2026-11-03

기준은 develop `1c57f5b`다. pull 이전 백업(`local work before develop pull 2026-11-02`)을 통째로 적용하지 않고, 최신 코드의 인증·기부 증빙·작성 승인·공개 스토리·계정별 수집 흐름에 기능별로 옮겼다.

## 복원한 기능

- 학교 선택: POSTECH, 한양대, 충남대, KAIST 이미지와 로고, 검색 및 확대 미리보기. POSTECH만 현재 3D 탐색을 지원한다. KAIST 이미지는 선택 화면용 AI 일러스트다.
- 캠퍼스: 원형/기울어진 패널 마커, 오이 검색 진입, 최신/오래된 순 정렬, 초록색 이야기 UI와 세로 캐릭터 이미지. 원격 갤러리·실제 카드·공식 기부 안내·서버 확인 후 수집은 유지한다.
- 검색: 공개 학교·닉네임, 오이 이름, 정확한 스토리 UUID. 현재 서버에 없는 학과·학번은 검색 UI에 넣지 않으며 사적인 계정 정보나 예시 문구로 추정하지 않는다. 검색 화면을 닫은 뒤 상세 화면으로 이동한다.
- 배치: 지도 표시 배율은 AR 높이와 독립적인 1m 기준이며 위치 편집의 확대 범위는 6m다. 좌표 저장·작성 승인은 최신 이야기 편집기를 사용한다.
- 기본 카메라: 주변 오이를 자동 탐색하고 기존 캐릭터 촬영 모드로 전환할 수 있다. 본 앱의 공개 `oi_stories`를 익명 권한으로 조회하며, 기기 예시를 공개 데이터에 섞지 않는다.
- 주변 AR: 유효한 최신 GPS에서 진입 25m, 이탈 35m, 최대 12개를 선택한다. 이동에 따라 선택을 갱신하고 공개 목록은 30초마다 확인한다. 숨김·삭제·위치 수정·조회 실패 시 오래된 앵커를 제거한다. 탭한 이야기도 공개 여부를 다시 확인한다.
- 지도→카메라→지도 복귀 시 기존 렌더러 해제/재생성 처리를 유지한다.

## 최신 develop 구현으로 유지한 부분

`OiServiceAPI`/`OiRemoteStore`, `oi_mutate`, 증빙·이야기 검토, 계정별 초안·수집, App Clip을 그대로 사용한다. 이전 `CampusShared*` API와 구형 Supabase 마이그레이션을 다시 넣지 않는다. 새 서버 배포나 DB 마이그레이션은 이 복원에 필요하지 않다.

오이 심기 버튼은 현재 계정·작성 승인·내 이야기 화면으로 연결한다. 카드 요청은 아직 서버 기능이 없어 준비 중으로 표시한다. 예시 카드 요청을 실제 요청으로 복원하지 않는다.

현재 `OiLiveStory` 계약에는 별도 AR 높이·방향이 없으므로 공개 AR은 기존 develop과 동일하게 기본 1m/0도를 사용한다. 예전 기기 저장의 개별 높이·방향을 공유 DB에 옮기려면 팀의 스키마와 저장 RPC 변경을 먼저 합의해야 한다. 주변 AR 모델은 기존 `helmet-oi.usdz` 공통 모델이며, 각 카드 그림에 맞는 개별 3D 모델 연결은 별도 작업이다. GPS·나침반과 감지한 바닥으로 근사 배치하며 정확한 물리 위치를 보장하지 않는다.

## 검증

- 실제 iPhone 대상 서명 빌드와 Simulator 빌드 성공.
- Jun iPhone 설치·실행 후 기존 `CampusRendererCheck`로 AR 전환 3회와 핀치 검사 PASS, `CampusPlacementCheck`로 1m 표시·10cm 이동·렌더러 복원 검사 PASS. 진단 배치는 메모리에만 생성하며 저장하지 않는다.
- 시뮬레이터에서 POSTECH·충남대·KAIST 선택 이미지와 로고 표시 확인.
- `run-campus-checks.sh`: 최신/오래된 순, 검색, 서버 확인 후 수집.
- `run-campus-placement-checks.sh`: 좌표 왕복, 고정 지도 배율, AR 높이 보존, 정밀 이동과 유효성.
- `run-campus-nearby-checks.sh`: A→B→C 이동, 진입/이탈 거리, 오래된 GPS, 수정·삭제, 중복 제거와 최대 개수.
- `run-oi-service-checks.sh`: 공개 권한 조회, 비공개 스토리 제외, 실패 처리, 기존 계정·증빙·초안 계약.
- 기존 MY·App Clip·AR 카메라 수명주기 검사.

실제 캠퍼스를 걸으며 확인하는 GPS/나침반 정확도와 최종 사용감 검증은 별도로 필요하다. 개인 서명, 프로비저닝 파일, Service.local.plist는 기능 커밋에 포함하지 않는다. 원본 백업과 stash는 유지한다.
