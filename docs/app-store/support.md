# 오이기부 지원

오이기부 앱의 로그인, 이야기 작성·공개, 카드 수집, 기부 자료 제출 또는 회원 탈퇴에 관해 문의하려면 [개발 저장소 지원 이슈](https://github.com/DeveloperAcademy-POSTECH/2026-C6-A01-BenchMark/issues)에 문의해 주세요.

문의에는 앱 버전, 사용하는 기기와 iOS 버전, 발생한 화면과 오류 설명을 적어 주세요. 암호, 로그인 인증코드, 기부 증빙 원본 등 민감한 자료는 공개 GitHub 이슈에 첨부하지 마세요.

- 회원 탈퇴: 앱의 **MY → 설정 → 회원 탈퇴**에서 본인 확인 후 진행할 수 있습니다.
- 실제 기부 납입 확인과 공식 영수증은 기부금을 받은 기관에 문의해 주세요. 오이기부 앱은 직접 기부금을 받지 않습니다.
