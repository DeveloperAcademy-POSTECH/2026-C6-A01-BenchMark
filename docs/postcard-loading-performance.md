# 엽서 사진 로딩 최적화 · #400

2026-11-16 적용·측정 기록.

## 구현

- `CampusPostcard` 전용 `OiPostcardImageCache`는 원본 PNG/JPEG 바이트와 해상도를 보존한다. 재압축·다운샘플링을 하지 않는다. 디코딩과 화면 표시 준비, 디스크 I/O는 별도 actor에서 직렬 처리한다. 기존 PNG 형식 검증과 배경 메타데이터를 유지한다.
- 메모리 캐시는 최대 2개·16MiB이며 이미지의 bytesPerRow×height를 비용으로 쓴다. 같은 경로의 요청은 하나의 Task를 공유한다. 호출자 취소는 다른 대기자를 취소하지 않고, 실패한 작업은 다음 시도에서 다시 준비한다.
- 계정 초기화·공개 이야기 목록 변경 시 세대를 바꾸고 진행 작업을 취소한다. 이전 세대 결과를 적용하지 않는다. 디스크는 세대별 해시 키, 5분 만료·64MiB 한도와 파일 보호를 사용한다. 앱 재실행 후 이전 세대 캐시를 재사용하지 않는다. 만료 파일은 다음 쓰기 때 정리한다.
- 이야기 목록 진입 후 2.5초 기다려 첫 카드 앞면 한 장만 순차 준비한다. 저전력 모드나 정상 이외 열 상태에서는 사전 준비를 시작하지 않는다. 앞면 표시와 사전 준비는 같은 경로의 진행 작업을 공유하며 뒷면은 실제 뒤집을 때 읽는다. 원래 뒤집기 애니메이션·투명 모서리·사진 배치·저장/공유 원본을 유지한다.
- 완성 엽서 PNG와 기존 이야기 사진 경로에 모두 적용한다. 원격 저장소가 없는 예시의 기존 이미지 표시 경로는 유지한다. 운영자 검토·저장/공유는 기존의 원본 다운로드 경로를 사용한다. 서버 계약·DB 변경은 없다.

## 검증

시뮬레이터에서 캐시 중복 요청 공유·대기자 한 명 취소 격리·실패 재시도·계정 변경 후 늦은 완료 차단·원본 PNG 색과 알파·1800×1200 JPEG 해상도·엽서 배경 메타데이터·양면 내보내기·뒤집기·실제 엽서/App Clip 캡처 등 엽서 검사 10개와 최신 develop 교육지구 계정·권한 통합 검사 3개, 총 13개 검사가 통과했다. 기존 원본 파일·개인 서명·서비스 설정·기부 자료는 수정하지 않는다.

## 실기기 비교

Jun iPhone, iPhone 17 / iOS 26.7.3, Release, USB 연결, 사용자 지정 동일 엽서 첫 열기→뒤로→재열기로 비교한다. 앱 소스 사본에만 진단 표식을 추가한다. 최초 유효 기준 로그는 앞면 준비 1852.0ms·1461.2ms, 정상 열 상태였다. 표시 완료 표식이 없는 앞선 기록은 시간 비교에서 제외했다.

수정본 최초 비교는 0.327ms·0.147ms, 정상 열 상태였다. 이야기 목록의 사전 준비가 완료된 뒤 처음 카드를 연 결과다. 이 값은 `CampusPostcard` 이미지 작업 시작→승인 앞면 준비까지의 시간이며 탭→화면 전환·실제 디스플레이 표시 완료 시간이나 인터넷 첫 다운로드 시간이 아니다. 캐시가 없는 다운로드 자체가 1ms 미만이라는 뜻이 아니다.

첫 두 카드를 400ms 후 준비하던 후보가 CPU·메모리 감소를 입증하지 못해 사전 준비를 지도 움직임 뒤 2.5초·한 장으로 제한하고 메모리 캐시도 16MiB로 낮췄다. 원본 화질 보존과 즉시 재열기를 위해 작은 디코딩 캐시 비용은 남는다.

최종 설정의 유효 로그는 이야기 사진 경로에서 첫 2278.1ms·재열기 5.119ms였다. 앞선 기준 로그는 완성 PNG 경로이고 최종 로그는 이야기 사진 경로이므로 첫 로딩·CPU·메모리 표를 동일 파일의 엄밀한 전후 개선률로 해석하지 않는다. 각 기록은 사용자 첫 열기→뒤로→재열기와 그 앞뒤 지도 구간을 포함하며 기록 길이는 약 44~52초다. GPU는 카드가 정지한 별도 30초 구간에서 측정하며 사진 로딩/뒤집기 중 GPU 개선을 뜻하지 않는다. USB 연결 중이며 절대 전력(W)·장시간 온도/배터리 변화는 측정하지 않았다.

앱 이름/PID 연결 실패와 8초 뒤 대상 프로세스가 종료된 직접 실행 기록은 제외했다. 이후 Activity Monitor 기기 전체 기록에서 설치 경로와 일치하는 실제 앱 PID의 표본만 추출했다(다른 같은 이름 프로세스 제외). 진단 표식과 원본 trace는 커밋하지 않는다.

최종 설정 정지 카드 30초에서도 앱의 Metal 명령 버퍼 제출은 0회였다. 원본 엽서 PNG를 실제 앱의 publication 렌더러로 생성해 캐시에 통과시킨 뒤 스캘럽 투명 모서리 판정·1086×1506 해상도·종이 색이 그대로인지 별도로 검사해 통과했다. 최종 일반 Release 빌드와 본 앱/내장 App Clip 서명 검증이 통과했다.

운영 이미지를 추가로 취득하지 않고 로컬에서 생성한 엽서 PNG로 해상도·알파·색상 보존을 검사했다. 원격 개인 콘텐츠를 새 파일로 저장하지 않았다.
