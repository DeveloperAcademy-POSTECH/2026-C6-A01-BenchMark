## 데이터와 승인 경계

- 기존 `oi_stories`, `oi_story_media`, `oi_assets`, `oi_writing_grants`, 비공개 초안 저장을 재사용한다. DB 마이그레이션·운영 서버 배포가 필요하지 않다.
- 작성 승인과 공개 승인은 별개다. 검토 대기·공개·숨김·삭제 서버 상태를 기기 초안으로 우회하여 편집하지 않는다. 실제 권한·개수·revision 충돌은 서버가 최종 검증한다.
- 중간 입력은 `OiDraftVault`에 계정별로 자동 저장한다. 이전 기록은 선택적 새 필드가 없어도 복원된다. 기기에만 저장된 초안도 목록에서 다시 연다.
- 사진 선택은 매번 독립적인 배치다. 이전 선택을 다음 선택에 중복 추가하지 않는다. 서버 첨부 순서를 우선 표시하고 새 사진을 뒤에 추가한다. 업로드된 사진은 삭제 후 교체하며 기존 미디어의 물리적 Storage 삭제 정책은 변경하지 않는다.
- 공개 확인 화면은 실제 공개될 프리셋을 보여준다. 커스텀 색·의상 설정은 로컬 미리보기라는 사실을 별도로 표시한다.

## 의도적인 디자인 조정·남은 작업

- 위치 화면은 Figma의 평면 지도 대신 사용자가 요청한 최신 POSTECH 3D 지도와 기존 정밀 배치 도구를 사용한다. 검색된 건물 중심을 곧바로 배치 좌표로 쓰지 않는다. 건물 외곽·허용 영역·지형 검사는 그대로 유지한다.
- 현장 AR 정확도는 GPS/방위/3D 모델 기준점 오차에 영향받는다. 지도에서 10cm 조정이 가능하다는 것이 현장 10cm 정확도를 보장하지 않는다.
- Figma의 테마·감정과 단계별 외형은 반영하되 제목 100자·본문 10,000자 등 기존 서버 허용 길이를 유지한다. 사진 15장 예시·티켓·코인·최소 기부금은 운영 정책으로 확정하지 않는다.
- 흰 반팔티·후드티·가디건·포스텍 과잠과 흰 긴바지/반바지의 8개 조합은 원본 몸체가 맞는 USDZ로 제공한다. 포즈/모자는 미제공이며 카드 크기·패턴·테두리는 틀만 제공한다. 공유 커스텀 저장과 다른 기기의 재현에는 별도 DB/API 및 자산 계약이 필요하다. 상세 구현은 [의상 조합](wardrobe-customization.md)을 따른다.
- 기존 약관 초안은 재사용했다. 이번 UI 작업이 최종 동의문·사진 권리·증빙 운영 정책의 확정을 의미하지 않는다.

## 자유 비율 사진 자르기 — 2026-11-03

**사진을 고정하고 자르기 격자를 조절**한다. 사진 선택 → **자르기** → 모서리·가장자리 손잡이로 가로·세로를 각각 조절 → 격자 안쪽을 드래그해 이동 → **적용** 순서다. 정사각형·가로형·세로형 등 비율 제한이 없으며, **전체 선택**은 사진 전체를 선택한다. 취소 시 첨부 사진은 변경하지 않는다. 실제 편집기는 `OiPhotoCropEditor`를 사용한다. 사진 보관함 원본은 수정하지 않고 업로드된 사진의 편집 제한도 유지한다.

`OiPhotoCropGeometry`는 선택 영역의 가장자리가 교차하거나 사진 밖으로 나가지 않도록 제한한다. 사진은 전체가 보이는 aspect-fit으로 고정하고 그 프레임을 기준으로 선택 영역을 정규화하여 `OiPhotoProcessor`가 실제 픽셀을 자른다. 화면 크기 변경 때도 선택 영역을 유지한다. 여덟 손잡이는 VoiceOver의 확대/축소 조절 동작을 지원한다.

검증: Debug 시뮬레이터 빌드 성공. `OiCreationPracticeTests` 3개와 `OiPhotoCropTests` 4개 통과(여덟 손잡이의 개별 크기 변경·경계 제한, 화면 크기 변경, 자유 비율의 실제 저장 픽셀·색상, 회전 후 자르기, 잘못된 영역 거부). iPhone 17 / iOS 26.5 시뮬레이터에서 사진 두 장 선택 후 두 번째 사진의 모서리·가장자리 드래그, 격자 내부 이동, 적용 결과와 선택 사진 유지, 전체 선택 및 취소 시 기존 사진 보존을 확인했다. 이번 수정본의 실기기 설치는 수행하지 않았다.

이슈 #128 작업의 최신 develop `d0371b9` 통합 검증: `OiStoryEditor`의 단계별 UI에 develop의 초안 복원 오류·다시 시도·원본 보존 후 나가기 경로를 함께 유지했다. 복원 실패 중에는 입력·사진 편집 및 저장을 열지 않는다. 양쪽의 테스트와 설계 문서를 보존했다. 통합 후 Debug 시뮬레이터 빌드와 `OiFlowChecks` 전체 33개, 서비스·손상 초안 복구·계정 통합 시 초안 복사·계정 연결 흐름 스크립트 4개가 통과했다.
