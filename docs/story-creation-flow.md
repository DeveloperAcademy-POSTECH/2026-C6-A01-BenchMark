## 데이터와 승인 경계

- `oi_stories`, `oi_story_media`, `oi_assets`와 비공개 초안 저장을 재사용한다. `oi_writing_grants`의 기존 연결은 이력으로 남는다. 서버 설정과 검증은 [Supabase 연동 문서](supabase-flow.md)를 참고한다.
- 검토 대기·공개·숨김·삭제 서버 상태를 기기 초안으로 우회하여 편집하지 않는다. 계정·소유권·상태·revision 충돌은 서버가 최종 검증한다. 운영자 콘텐츠 검토를 거친 이야기만 공개된다.
- 중간 입력은 `OiDraftVault`에 계정별로 자동 저장한다. 이전 기록은 선택적 새 필드가 없어도 복원된다. 기기에만 저장된 초안도 목록에서 다시 연다.
- 사진 선택은 매번 독립적인 배치다. 이전 선택을 다음 선택에 중복 추가하지 않는다. 서버 첨부 순서를 우선 표시하고 새 사진을 뒤에 추가한다. 업로드된 사진은 삭제 후 교체하며 기존 미디어의 물리적 Storage 삭제 정책은 변경하지 않는다.
- 공개 확인 화면은 실제 공개될 프리셋을 보여준다. 커스텀 색·의상 설정은 로컬 미리보기라는 사실을 별도로 표시한다.

### 모든 화면 이동과 인증 미리보기 — 2026-11-05 추가 확정

- 이야기 화면은 Figma처럼 발자국 아래에서 테마·감정·제목·이야기·사진·위치를 한 폼으로 보여준다. 이야기/이미지/위치 바로가기 버튼 행과 모든 화면 헤더는 이야기 화면에서 표시하지 않는다. 사진·위치는 본문의 사진 추가/위치 설정으로 열며 완료·뒤로가기는 이야기로 복귀한다. 이야기의 다음은 오이 커스텀으로 이동한다.
- 약관·오이·카드 화면의 **모든 화면** 메뉴에서 여섯 작성 화면, 3D 위치 지도, 공개 검토 확인, 접수 완료 미리보기, 기부 인증 미리보기를 연다.
- 기부 인증은 사용자 요청대로 제출 없는 디자인 미리보기다. 파일 선택·재첨부·인증 요청은 비활성화하고 상태 항목은 예시로 명시한다. 접수 완료 미리보기도 실제 요청을 보내지 않는다.
- 기부 인증 미리보기는 Figma `2911:752`의 씨앗 배지, PNG·JPEG·PDF 첨부 영역, 날짜별 인증 상태와 보상 배지를 표시한다. 화면의 씨앗 수와 인증 건수는 Figma 예시 값이다.
- 약관 체크는 `OiLocalDraft.agreedConsentClauseIDs`에 선택적으로 저장한다. 기존 초안에 필드가 없으면 미동의로 취급한다. 단계를 열거나 다음 버튼을 눌렀다는 이유로 동의·기부 승인·접수 상태를 바꾸지 않는다.
- 필수 입력이 부족하면 검토 확인 화면에 해당 화면으로 돌아가는 안내 버튼을 제공한다. 단순 이동은 기기 자동 저장만 수행한다.

추가 검증: `OiRemoteStoreTests.testInteractiveCreationNavigation`을 `OI_CREATION_INTERACTION_CHECK=all-screens`로 실행해 필수 본문·위치·이름이 빈 초안에서 여섯 단계를 모두 왕복했다. 실제 시뮬레이터 버튼으로 인증·접수 완료 미리보기를 열고, 검토 확인의 누락 항목 안내를 눌러 약관으로 복귀했다. 글·의상 보존, 자동 동의 없음, 서버 이야기 생성 없음 검사가 통과했다. 검토 요청 버튼은 필수 입력이 없을 때 비활성화됨을 화면으로 확인했다. 서비스·MY 검사와 약관/꾸미기 화면 크기별 렌더링, 임시 모드 해제 시 글·사진 보존 테스트도 통과했다.

## 사진 편집·3D 위치 직접 진입 — 2026-11-05 후속 요청

- Figma [3504:13187](https://www.figma.com/design/nEDJaJBFrdzBCa1WcgADHH?node-id=3504-13187)에 맞춰 사진 화면은 짙은 회색 배경, 취소·이미지 선택·완료, 사진 미리보기, 자르기·회전·삭제, 대표 사진 표시·썸네일·추가로 구성한다. 사진·위치에는 발자국, 이야기/이미지/위치 바로가기, 이전·다음이나 모든 화면 헤더를 표시하지 않는다. 이야기·약관·꾸미기의 단계 이동은 유지한다.
- 사진 설정 헤더는 Paperlogy 20pt 텍스트로 표시한다. 사진은 최대 296×400pt 미리보기와 60×75pt 썸네일을 비율을 유지한 채 채운다. 추가 버튼과 사진은 같은 타일 형태를 사용하며, 추가 버튼만 썸네일 줄의 맨 왼쪽에 고정한다.
- 이야기에는 사진 1~3장을 첨부한다. 사진 설정 화면은 `현재 개수 / 3`을 표시하고, 보관함에서는 남은 자리만큼 선택할 수 있다. 기존 사진이 3장을 초과하면 자동 삭제하지 않고, 직접 줄인 뒤 다음 단계나 검토 요청으로 진행한다.
- 자르기는 사진을 고정하고 8개 모서리·가장자리 손잡이로 격자를 자유 비율로 조절한다. 안쪽 드래그는 선택 영역을 이동하고 적용한 영역만 JPEG에 저장한다.
- 미리보기 위의 두 손가락 비틀기로 원하는 각도를 설정한다. 오른손가락을 내리고 왼손가락을 올리면 시계 방향이다. 손을 떼면 같은 변환을 사진 복사본에 저장한다. 빈 모서리를 방지하려고 중앙 기준으로 필요한 만큼 확대·잘라내며 미리보기와 저장 결과를 맞춘다. 회전 버튼은 왼쪽 90도 회전이다.
- 사진 화면의 취소는 진입 시 첨부 목록·삭제 상태로 되돌리고, 완료는 변경한 목록을 보관하고 이야기로 돌아간다. 원본 보관함과 기존 사진 복사본을 덮어쓰지 않는다. 서버에 이미 업로드된 사진은 기존 정책대로 삭제 후 교체한다.
- 위치 설정은 `OiLocationPicker`의 3D 지도 내용을 편집기 내에서 즉시 보여준다. 상단 취소와 하단 위치 확정으로 이야기에 복귀한다. 취소는 기존 위도·경도를 변경하지 않고, 확정만 새 좌표를 반영한다.

이번 후속 검증: 시뮬레이터 빌드 및 사진 자르기·임의 회전 6개 테스트와 실제 사진/위치 편집 화면 크기별 캡처 검사가 통과했다. `testInteractivePhotoCancelAndLocation`을 `OI_PHOTO_INTERACTION_CHECK=1`로 실행해 회전·삭제 후 취소 → 원본 목록 복원 → 다시 삭제·완료 → 3D 위치 진입·취소를 UI 자동화로 확인했다. 첫 자동화 실행은 제한 시간 내 경로를 마치지 못했고, 이후 지도 상단 취소가 숨겨지는 문제를 수정하여 재검증했다. 최종 검사에서 기존 사진 바이트·취소한 좌표 보존과 서버 이야기 생성 없음이 통과했다. 실제 iPhone의 두 손가락 제스처 감도와 사진 보관함 선택은 이번 검증 범위에 포함하지 않았다.

## 의도적인 디자인 조정·남은 작업

- 위치 화면은 Figma의 평면 지도 대신 사용자가 요청한 최신 POSTECH 3D 지도와 기존 정밀 배치 도구를 사용한다. 검색된 건물 중심을 곧바로 배치 좌표로 쓰지 않는다. 건물 외곽·허용 영역·지형 검사는 그대로 유지한다.

STEP 글자와 아래 제목은 애니메이션 밖에 두어 읽기 쉽게 유지하며 다른 버튼이나 레이아웃 크기는 바꾸지 않는다. 단계 이동 시 기존 반복 뷰가 제거되고 새 현재 버튼에서 시작한다. 동작 줄이기와 비활성 scene에서는 반복 애니메이터를 만들지 않는다. 별도 타이머·반복 Task 없이 기존 누름·선택 효과와 이동 콜백을 보존한다.

검증: iPhone 17 / iOS 26.5 시뮬레이터 대상 빌드 성공, `git diff --check` 통과. 기존 Swift 동시성·deprecated API 경고는 남아 있으며 이번 변경 파일의 컴파일 오류는 없다. 실제 기기의 깜박임 속도·단계 전환 체감과 동작 줄이기 설정 전환은 별도 확인 대상이다.

### 깜박임과 입체 눌림 동기화 — 2026-11-05 후속 요청

현재 발자국의 한 `PhaseAnimator`가 밝기·배율(1→0.94)·세로 이동(0→3pt)·기울기(0→-5도)·그림자 높이와 농도를 함께 바꾼다. 각 반주기 1.6초는 유지한다. STEP 글자는 발자국과 함께 움직이지만 밝기는 변하지 않으며, 아래 단계 제목·70pt 터치 영역·42pt 발자국 레이아웃 공간은 고정해 주변 UI가 밀리지 않는다.

실제 `ButtonStyle.Configuration.isPressed`는 환경값으로 발자국에 전달한다. 손으로 누르는 동안 자동 반복을 멈추고 기존 터치 축소·이동을 적용해 두 효과가 겹쳐 과하게 눌리지 않게 한다. 손을 떼면 현재 단계만 다시 반복하며, 동작 줄이기·앱 비활성 조건은 유지한다. 이전 섹션의 밝기만 바꾸던 동작을 이 동작으로 보완한다.

후속 검증: iPhone 17 / iOS 26.5 시뮬레이터 빌드 성공, `git diff --check` 통과. 실제 iPhone 설치 및 눌림 깊이·속도의 육안 확인은 이번에 수행하지 않았다.
