`OiPostcardBackgroundStyle`에 optional 시작·중간·끝·뒷면 로고 opacity를, 보호 초안 `OiCardDesign`에 optional 앞면 로고·오이 뒤 배경 opacity를 저장한다. nil은 기존 표시(곱셈 계수 1)를 보존하며 구형 기본 워터마크의 15% 표현도 유지한다. 오이 뒤 배경의 초기화/자동 색상은 RGB와 opacity를 함께 nil로 되돌린다. 표준 프리셋을 새로 고르면 배경 3색의 opacity도 원본 100%로 돌아간다.

## 2026-11-12 후속 · 오이 뒤 자동 배경

Figma `5400:6871`의 이미지 영역은 x=33, y=33, 296×436 크기의 단색 `#835C6E`이며, 그 위에 오이를 올린다. Step 4에서 오이가 보이는 앞면은 이 별도 배경을 사용한다. 로즈 종이 `#EECFDF`는 원본 조합을 그대로 사용한다. 다른 프리셋·직접 선택한 RGB는 같은 색상 계열을 유지하며 밝기를 55%로 낮추고 연한 색의 채도를 보강한다. 검정에 가까운 색은 최소 밝기를 두어 이미지 영역이 구분되게 한다. 컬러 피커를 움직일 때 밝기가 갑자기 바뀌지 않도록 연속적으로 계산한다.

별도 배경은 캐릭터 이동·확대와 독립된 고정 이미지 창에만 적용한다. 종이의 단색/그라데이션 효과, 이야기 뒷면은 유지한다. 오이를 숨기면 사진용 배경으로 돌아가며, 직접 넣은 사진과 패턴은 기존 순서대로 배경 위에 합성한다. 통합 배경 설정이 없는 구버전 초안은 이전 모습을 유지하다가 편집기의 기존 `prepareBackground`에서 설정을 가져온 뒤 새 배경을 적용한다.

실시간 미리보기와 제출용 PNG가 같은 합성 코드를 사용한다. 추가 AI 호출·이미지 파일 생성·서버 필드·초안 필드는 없다. 기존 승인된 앞면 PNG는 바꾸지 않으며, 새로 저장·검토하는 엽서에 반영한다.

2026-11-13 병합 전 검토에서 엽서 본문 편집도 이야기 작성 화면과 같은 입력 제한을 재사용하도록 보완했다. 45자를 넘는 예전 초안은 자동으로 자르지 않고 사용자가 한 글자씩 줄일 수 있다. 한도 초과 추가 입력과 붙여넣기는 반영하지 않는다.

병합 전 최종 검증: 서비스 회귀 검사와 실기기 서명 빌드가 통과했다. iOS 27.2 시뮬레이터의 엽서·작성 입력·공개 검토·계정 저장 검사 96개 중 93개가 통과했고, 기존 수동 조작용 검사 3개는 기본 비활성 상태로 제외됐다. iOS 26.3 시뮬레이터에서는 RealityKit 렌더 파이프라인 오류로 화면 캡처가 중단되어 같은 검사를 최신 런타임에서 수행했다. 실제 iPhone의 사진 선택·카드 공개 요청은 이번 자동 검사에 포함하지 않는다.

검증: 관련 테스트 5개가 통과했다. 로즈 안쪽 픽셀 `#835C6E`와 종이 영역 유지, 색상 변경 및 짙은 RGB, 캐릭터 이동과 배경 독립성, 오이 숨김/뒷면 유지, 724×1004 PNG 및 메타데이터 복원, 사진 색조·원본 보존을 확인했다. 컬러 피커의 밝기 전환을 연속적으로 보정한 뒤 해당 회귀 테스트를 다시 통과했다. 로즈·그린·스카이·크림·화이트·짙은 네이비 캡처를 확인했고 실기기 빌드도 성공했다.
