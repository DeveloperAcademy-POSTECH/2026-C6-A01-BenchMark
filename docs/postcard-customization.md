## 2026-11-12 후속 · 배경 선택 통합

사용자 요청으로 `배경`과 `엽서` 탭을 `배경` 하나로 통합했다. 배경색 하나와 단색/그라데이션 효과를 고르면 종이, 이미지 아래 배경, 뒷면에 같은 배경을 사용한다. 기존 두 색 설정은 이전 초안 호환용으로 남기고, 편집기를 열면 기존 종이 색을 단일 배경 색으로 가져온다.

`postcardBackground`는 optional 색상·효과 값이다. Figma `5400:6605`의 로즈 바탕 `#EECFDF`, 색상 영역 `#C76A94`·`#8B4A69`, 불투명도 80%, 두 타원 위치와 Gaussian sigma 100을 사용한다. iOS에서 색 번짐은 Core Image로 렌더링하고 16MB 캐시에 보관한다. 그린·코랄과 직접 고른 색에도 같은 효과를 적용한다. 단색은 색 번짐을 적용하지 않는다.

앞면 PNG에는 비개인적인 색상·효과 값만 versioned PNG Description에 함께 저장한다. 기존 파일 업로드·승인·공개 API 계약을 그대로 사용한다. 이미지 로더는 검증된 메타데이터를 UIImage의 약한 참조와 연결해 지도 뒷면에도 정확히 같은 배경을 적용한다. 메타데이터가 없는 예전 카드는 기존 색 추출 방식으로 표시한다. 본인 소유의 기기 초안은 기존 계정·작성자 경계를 확인해 편집 중인 배경을 미리 보여 준다.

후속 검증: 피그마 배경 PNG의 네 지점 RGB와 허용 오차 6 이내, 종이/사진 배경의 연속성, 저장·로드 후 같은 스타일 복원, 동일 카드의 snapshot ID 안정성, 이전 초안 decode, 기존 카드 공개 검토 계약, 402×874·375×667 배경 선택 화면 캡처가 통과했다.

## 2026-11-12 후속 · 오이 뒤 자동 배경

Figma `5400:6871`의 이미지 영역은 x=33, y=33, 296×436 크기의 단색 `#835C6E`이며, 그 위에 오이를 올린다. Step 4에서 오이가 보이는 앞면은 이 별도 배경을 사용한다. 로즈 종이 `#EECFDF`는 원본 조합을 그대로 사용한다. 다른 프리셋·직접 선택한 RGB는 같은 색상 계열을 유지하며 밝기를 55%로 낮추고 연한 색의 채도를 보강한다. 검정에 가까운 색은 최소 밝기를 두어 이미지 영역이 구분되게 한다. 컬러 피커를 움직일 때 밝기가 갑자기 바뀌지 않도록 연속적으로 계산한다.
