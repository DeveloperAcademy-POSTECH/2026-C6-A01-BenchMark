# 교육지구 2.0 지도 체험 — 2026-11-12

사용자가 공식 POSTECH 예상 조감도와 배치도를 참고해 기존 오이기부 지도에 구슬 건물을 연결하도록 요청했다. 이 작업은 OiDonation의 캠퍼스 표시와 독립 시연 화면을 연결하며 실제 모금 운영을 추가하지 않는다.

## 출처와 배치

- 공식 페이지: https://www.postech.ac.kr/kor/innovation/education_district_cp.do
- 조감도: `/_res/postech/kor/img/sub/education_district_top01.jpg`
- 배치도: `/_res/postech/kor/img/sub/education_03.png`
- 사용자 제공 현황: 도서관 옆 포스빌6 철거, 포스빌6·주차장 부지에 건립 예정.
- 지도 원본의 포스빌6 ID는 `136961801`이다. 포스빌6·주차장 부지 전체를 높이 제한 없이 삼각형에서 잘라내고 명칭도 숨긴다. 삼각형 중심이 부지 밖에 있어도 부지와 겹치는 부분은 제거하고, 부지 밖 부분은 보존한다. 부지 안 나무는 줄기와 수관을 함께 제거해 반쪽 수관을 남기지 않는다. 원본 oimesh와 좌표 파일, 포스빌1·2·5 및 C5·도서관은 유지한다.
- 부지 경계는 새 모델의 전체 표면과 철거된 포스빌6을 포함하는 12점 볼록 다각형이다. 실제 좌표는 `CampusEducationSite.boundary`가 단일 기준이며 경계의 최소/최대값도 여기서 계산한다. 평탄한 포장면 높이는 0.45이며 경계는 원래 지형 높이에 연결한다. 부지 안에는 새 오이를 배치하지 않는다.
- 건물 중심은 지도 XYZ `(52, 0.45, 41.1)`, 회전 1.96rad, 형상 배율 1.2795299다. 정면이 C5를 향하고 제공 모델의 왼쪽 연결 다리 끝 `(-6.3734664, 1.076984, -2.9537949)`에서 박태준학술정보관 외벽까지 연장한다. 지도는 미터당 0.12단위를 쓴다. 새 크기의 건물과 포장면이 C5·도서관과 겹치지 않는 **개념 배치**이며 측량/시공 좌표가 아니다. 정확한 부지 경계·접속 층은 추후 도면과 대조해야 한다.
- 사용자 제공 `Meshy_AI_Modern_Architecture_Building_20261112_generate.blend`의 월드 공간 표면을 직접 샘플링한다. 이전의 이미지 해석 기반 절차적 건물을 교체했다. 원본 파일은 수정하지 않는다. 96,000개 점 위치·법선·명도와 웹용 깊이 가림 메시를 `meshy-building-surface-20261112-v1`로 기록하고 웹·지도·앱 안 웹 체험에서 동일한 바이너리를 사용한다. 형상 전체에 한 번의 회전·균일 배율만 적용한다.
- 공식 페이지의 **건축면적 13,054.01㎡**와 제공 모델의 평면 볼록 외곽 면적을 맞춰 균일 축척을 산정했다. 그 결과 모델의 가로·깊이·높이는 **약 136.48 × 120.59 × 41.98m**다. 지도 내 학술정보관의 평면 면적 약 6,019㎡와 비교하면 약 **2.17배**다. 모델이 임의 단위이고 공식 페이지에 폭·깊이·최고 높이가 없으므로 이는 **공식 건축면적을 기준으로 한 추정치**이며 실제 치수 확정값이 아니다. 오목한 평면·현관·연결 통로 등 건축면적 산정 방식 차이는 도면 확보 후 검증한다.

## 표현과 흐름

- 지도는 밝은 흰 구슬로 표현한다. 실제 기부 집계와 연결되지 않았으므로 지도에 파란 인증 비율이나 임의 모금액을 표시하지 않는다.
- 2026-11-12 후속 밝기 조정: 어두운 청회색 재질 대신 흰색 PBR 재질을 사용한다. 0.84–1.0의 6단계 색상값과 0.35–0.70의 발광 강도로 빛을 덜 받는 면에도 밝기를 더하면서 구슬의 입체 음영을 남긴다. 웹 자산의 부위별 명도 순서는 루버·층 테두리를 구분하는 미세한 차이로 유지한다. 구슬 좌표·크기·개수, 지도 조명·포장색과 내부가 비어 있는 표현은 유지한다.
- `교육지구 2.0 · 건립 예정` 표지 또는 3D 건물을 누르면 확대하고 공식 조감도·배치도·사업 안내를 연다. 선택 중에는 주변 오이와 수량 배지를 잠시 숨기고 닫을 때 이전 카메라·표시를 복원한다. 원래 오이 데이터/위치는 바꾸지 않는다.
- 높이 280pt의 작은 안내창에서는 배경 지도와 구슬을 어둡게 덮지 않고 지도 조작을 허용한다. 안내창을 크게 펼치면 기존 시트 배경 처리를 유지한다.
- 안내에서 `빛으로 지은 이야기 체험`을 누르면 앱에 포함한 검정 배경 WebGL 프로토타입을 연다. 전체화면 체험 중 RealityKit 지도 렌더러를 해제하고 닫을 때 복원한다.
- 구슬 흩어짐/재결합·회전/핀치·사진/메시지·인증 시연은 기존 웹과 같다. 모든 금액과 인증은 **시연**이다. 기존 공개 오이 카드·계정·기부 증빙 승인과 연결하지 않는다.
- 사진/메시지는 이 앱의 로컬 WebKit 저장소에만 남는다. 서버로 보내지 않는다. 향후 실제 참여자의 오이 카드와 연결하려면 서버의 참여 ID·승인된 공개 이야기 계약이 필요하다.

## 성능과 자산

- 지도: 멀리서 24,000개, 가까이서 96,000개 구슬. 웹의 공간 분산 순서를 유지한 앞부분을 사용하며 일정 간격으로 점을 건너뛰어 층과 벽이 빠지던 샘플링을 제거했다. LOD 전환은 반경 85/105 히스테리시스를 사용한다.
- 구별 Entity/충돌체 대신 LOD별 단일 메시를 캐시한다. 구 하나는 매끄러운 법선을 가진 8개 삼각형으로 표현하며 매 프레임 좌표를 갱신하지 않는다. 건물 선택 충돌체는 하나다. 반투명 정렬과 개별 구 그림자를 사용하지 않는다.
- 2026-11-12 후속 요청으로 건물의 불투명 청회색 바탕과 연결 다리의 내부 상자를 제거했다. 건물·다리는 표면의 구슬만 렌더링하며 틈으로 뒤쪽 구슬·지도가 보인다. 웹의 가림 메시는 원본 검증용 자산에 남지만 네이티브 GPU 메시로 만들지 않는다. 지도까지 뚫려 보이게 하는 OcclusionMaterial도 사용하지 않는다. 평탄한 부지 포장면과 경계 옹벽은 유지한다.
- `education-district-points.bin`은 4,128,020바이트다. 96,000개 점의 float32 XYZ·법선·명도, 웹 깊이 가림 메시의 정점 120,000개(40,000삼각형), 바닥 보정 1.9686406을 담는다. 헤더·크기·유한값·법선 길이를 검사한다. 원본 약 253만 삼각형을 런타임에 로드하지 않는다.
- Blender에서 `scripts/export-education-model.py`를 실행해 표면 바이너리와 `education-district-geometry.json`을 만든다. 메타데이터에 소스/결과 SHA-256, 원본 범위, 표면 샘플 간격, 평면 외곽, 추정 치수를 기록한다. 현재 바이너리 SHA-256은 `3ce3c0ee8a62779b701b3fa4547a0d7d5fcec3acfbb62ffd2ecaa66bb3b1f94b`다.
- `node scripts/export-education-geometry.mjs <웹 dist 디렉터리>`는 검증된 바이너리를 웹으로 복사하고 웹 HTML/CSS/JS와 모델의 네 방향 렌더링을 앱 HTML에 묶는다. 앱의 WKURLSchemeHandler가 `oi-education://bundle/surface.bin`으로 동일 번들 바이너리를 제공하므로 HTML에 4MB 자산을 base64로 중복 삽입하지 않는다. 기존 file-origin과 로컬 사진·메시지 저장소는 유지한다.
- 상세: 모바일 48,000개 WebGL 점, 30fps 상한, 가벼운 모드 24,000개, 데스크톱 96,000개. GPU 정적 버퍼는 5,664,000바이트다. 배경 상태와 화면 밖에서는 멈춘다. HTML/CSS/JS/참고 이미지와 별도 번들 바이너리로 인터넷 없이 실행한다.
- 공식 사이트 링크만 사용자 조작 시 외부 브라우저로 연다.

## 검증

- `CampusEducationDistrictTests`: 전체 웹 자산 SHA-256, 배치 메시·단일 충돌체·LOD 위치/방향/범위 유지, 포스빌6 전체 포함과 C5/도서관 보존, 다리 접속과 정면 방향, 경계 삼각형 절단, 경계 나무 전체 제거, 실제 지도 정면·좌·우·뒤·위 렌더링 검사.
- iPhone 18 Pro iOS 27.2 시뮬레이터에서 지도 표지 → 확대/공식 안내 → 상세 시연 → 닫기/지도 복원 경로를 확인했다.
- OiFlowChecks의 CampusEducationDistrictTests 6개와 기존 지도 색상/원본 메시 보존·지도 중심 위치 선택 검사 2개, 총 8개가 통과했다. 최종 부지 경계 수정 후 정면·양측면·후면·위쪽 렌더링도 확인했다.
- 불투명 채움 제거 후 CampusEducationDistrictTests 6개가 다시 통과했다. 건물 바탕과 다리 내부 상자가 없고, 기존 웹 좌표 해시·배치·LOD가 유지되는지 검사했으며 다섯 방향에서 구슬 사이로 지도가 보이는 렌더링을 확인했다.
- 흰색 재질·발광 강도 조정 후 같은 6개 테스트가 통과했다(`OiEducationBrightWhiteFinal.xcresult`). 정면·좌·우·뒤·위 렌더링에서 흰 구슬과 층·옥상 윤곽을 확인했고, 실제 앱의 작은 안내창에서도 지도 밝기가 유지됨을 확인했다. 기존 6개 재질 슬롯과 구슬 메시를 재사용하며 내부 면·추가 조명·블룸은 만들지 않는다.
- Jun iPhone용 Debug 빌드·설치·프로세스 실행 성공. 실제 기기 화면/터치와 장시간 사용은 사용자 확인 대상이다.
- 실제 iPhone의 장시간 발열·배터리·성능은 별도 확인 대상이다.

## 최신 develop 통합 검증 — #292

최신 공개 오이·작성자 배치 로더와 카드 패턴/배경 구현을 유지하면서 통합했다. 별도 공개 오이 로더를 중복 추가하지 않는다. `Oi292IntegrationFinal.xcresult`에서 교육지구 6개, 팔레트 보존 1개, 공개/작성자 오이 3개, 카드 패턴·색 영역 2개 등 총 12개 검사를 통과했다. 통합본 시뮬레이터 빌드·실행도 성공했다. 개인 기기용 서명 설정은 PR에 포함하지 않는다.

2026-11-12 병합 전 후속 검증: #288의 렌더러 해제·레이아웃 무효화 최적화를 유지하며 통합했다. 새 `suspendRendering()` 경로를 안내 화면과 검사에 적용했고, `Oi294MergeVerified.xcresult`의 기존 12개 검사와 뷰포트/마커 변경 검사 1개, 총 13개가 통과했다. 독립 웹 소스는 develop에 병합하지 않고 이슈 #293에 보관한다. 앱에 포함된 자체 실행 체험은 유지한다.
