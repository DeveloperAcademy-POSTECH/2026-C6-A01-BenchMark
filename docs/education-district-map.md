# 교육지구 2.0 지도 체험 — 2026-11-13

사용자 요청으로 네 방향 기준 이미지에서 재구성한 최신 웹 구슬 건물을 OiDonation 캠퍼스에 적용한다. 실제 모금 운영이나 공개 이야기 정책은 변경하지 않는다. 아래는 현재 구현이고, 마지막의 이전 검증 이력은 당시 모델 기준이다.

## 기준 형상과 출처

- 공식 사업 페이지: https://www.postech.ac.kr/kor/innovation/education_district_cp.do
- 공식 조감도 `/_res/postech/kor/img/sub/education_district_top01.jpg`, 배치도 `/_res/postech/kor/img/sub/education_03.png`를 배치 참고 자료로 사용한다.
- 현재 형상은 `four-view-architecture-20261113-v4`다. 사용자 기준 정면·좌·우·뒤 이미지에 맞춰 재구성한 웹의 43개 표면 패치와 동일한 좌표를 사용한다. 이전 Meshy `.blend`에서 추출한 형상은 더 이상 앱 자산의 기준이 아니다.
- 비대칭 외벽, 아래쪽 경사면, 왼쪽 사다리꼴 상부, 열린 중정, 층별로 다른 테라스, 낮은 계단식 공간, 왼쪽 연결 다리와 사선 연결부를 유지한다. 표면 내부를 구슬로 채우지 않는다.
- 가려진 연결부·회랑 깊이·테라스 접합과 계단 높이는 이미지 기반 추정이다. 이 추정 범위는 자산 JSON에도 기록한다.

## 캠퍼스 배치와 크기

- 지도 단위는 0.12단위/m, X는 동쪽, Z는 남쪽이다. `CampusEducationSite`의 중심 `(51, 1.05, 41.3)`, 회전 1.96rad, **균일 배율 1.12**가 배치 기준이다. 정면은 C5를 향한다.
- 예상 외곽 크기는 **약 136.91 × 95.76 × 49.12m(가로·깊이·높이)**다. 외곽의 평면 볼록 영역 약 11,213㎡는 지도 학술정보관 평면 약 6,019㎡의 1.86배다. 조감도·주변 건물·도로 여유를 함께 고려한 개념 축척이며 측량/시공 치수가 아니다.
- 공식 건축면적 13,054.01㎡와 모델의 볼록 외곽 면적은 산정 방식이 다르므로 같다고 놓고 확대하지 않는다. 공식 자료에 없는 폭·깊이·최고 높이를 확정값으로 표현하지 않는다.
- 22점 볼록 부지는 새 건물 전체와 철거 대상 포스빌6(`136961801`)을 포함한다. 경계 삼각형을 잘라 부지 안의 기존 건물을 제거한다. 나무는 줄기·수관 전체 단위로 처리한다. 원본 oimesh 파일, 학술정보관(`136182168`), C5(`397201294`)와 나머지 건물은 보존한다.
- 도로 중심선과 실제 폭으로 보호 영역을 계산한다. 모든 건물 구슬은 구의 반경까지 포함해 보호 도로 밖에 있는지 검사한다. 재개발 대상 주차장 내부 도로 `1012928008`, `1012928009`만 보호 대상에서 제외한다. 건물에 맞추려고 앞 도로를 옮기거나 폭을 줄이지 않는다.
- 웹 건물의 연결 다리 끝 `(-7.25, 1.7005, -0.18)`을 월드 좌표로 변환해 같은 축을 따라 학술정보관 외벽까지 연장한다. 공중 다리도 구슬 표면만 그리며 내부 상자를 넣지 않는다. 실제 접속 층과 구조는 정식 도면으로 추가 대조해야 한다.

## 지형 연결

- 2026-11-13 사용자 요청: 교육지구 아래와 주변의 옛 주차장·진입로를 **주변과 같은 녹색 잔디**로 바꾼다. 별도로 그리던 회색 바닥을 제거한다. 앞의 큰 도로와 주차장에 속하지 않는 기존 길은 유지한다.
- `CampusEducationLandscape`의 지형 교체 경계는 건물 부지 바깥의 남은 주차장과 두 진입로까지 포함한다. 도로 폭과 주변 건물 기초를 보호 영역으로 빼고, 교체 범위 안의 기존 잔디·아스팔트·포장·경계석 삼각형을 정확히 절단한다. 큰 도로와 보호된 길의 원래 정점·높이는 변형하지 않는다.
- 옛 진입로가 기존 보행로를 가로지르던 지점은 아스팔트 면을 남기는 대신 보행로 재질로 연결한다. 큰 도로까지 잔디나 보행로로 덮지 않는다.
- 부지 높이는 1.05다. 기존 주차장 면을 높이만 바꾸는 방식 대신 약 2m 간격의 공유 정점 격자로 잔디 표면을 다시 만든다. 부지 뒤쪽은 최대 6지도단위(약 50m), 앞쪽은 1.5단위(약 12.5m) 범위에서 원래 지형으로 연결하며 바깥 이음새에서 높이 변화량이 0이 된다. 연속 지면 높이로 법선을 계산하고 수직 옹벽·지하 채움은 추가하지 않는다.
- 새 잔디는 기존 캠퍼스 잔디 타일에 합쳐 원본/살구 크림 팔레트와 조명을 공유한다. 개별 잔디 Entity나 추가 draw call 없이 한 번 생성하며, 격자 정점 수는 검사에서 20,000개 미만으로 제한한다. 경계 밖 나무는 줄기와 수관을 함께 이동한다.
- `CampusHeightField`의 지면 선택과 화면 메시가 같은 보간 함수를 사용한다. 기존 캠퍼스 지형의 큰 굴곡은 남기며 부지 내부에는 새 오이를 배치하지 않는다.

## 표현과 흐름

- 지도에서는 밝은 흰색 구슬을 사용한다. 실제 기부 집계와 연결하지 않으므로 파란 인증 비율이나 임의 모금액을 지도에 표시하지 않는다.
- 흰색 PBR 재질 6단계(색상 0.84–1.0, 발광 0.35–0.70)로 구슬의 입체감을 유지한다. 건물 내부 면, 불투명 배경 메시, 추가 조명, 블룸은 만들지 않는다. 건물 아래의 잔디 지면은 건물 내부 채움과 별개다.
- `교육지구 2.0 · 건립 예정` 표지 또는 건물을 누르면 확대하고 공식 안내를 연다. 선택 중 주변 오이·수량 배지를 잠시 숨겼다가 닫으면 이전 카메라·표시를 복원한다. 기존 오이 데이터와 위치는 바꾸지 않는다.
- 작은 안내창에서는 지도 밝기와 조작을 유지한다. `빛으로 지은 이야기 체험`은 앱에 포함된 검정 배경 WebGL 체험을 열고 그동안 RealityKit 지도 렌더러를 해제한다. 닫으면 지도를 복원한다.
- 웹의 흩어짐·복원·회전·핀치·사진·메시지·인증은 **시연**이다. 사진과 메시지는 앱의 로컬 WebKit 저장소에만 저장하며 기존 서버 계약이나 기부 보상 조건을 추가하지 않는다.
