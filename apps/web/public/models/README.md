# 캐릭터 교체

`postech.glb`, `kaist.glb`를 이 폴더에 넣으면 /camera에서 자동으로 불러옵니다.
현재 공식 캐릭터 파일은 제공되지 않았습니다. 화면에 표시되는 임시 3D 모델은 공식 캐릭터가 아닙니다.

- 텍스처 내장 glTF 2.0 GLB, Y축 위, 정면 +Z 권장
- Draco 압축 지원. KTX2 텍스처는 현재 미지원이므로 PNG/JPEG 텍스처로 내보내기
- 각 모델 5MB 이하, 5만 삼각형 이하, 1K~2K 텍스처를 초기 목표로 사용
- 로더가 모델 중심·높이를 자동 정규화합니다. 화면에서 방향과 크기를 조절할 수 있습니다.
- 애니메이션은 현재 재생하지 않습니다. 기본 포즈로 내보내세요.
- 모델별 라이선스·출처는 파일과 함께 기록하세요.
