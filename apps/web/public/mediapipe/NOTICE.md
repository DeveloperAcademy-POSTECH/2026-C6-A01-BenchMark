# MediaPipe runtime and model

WASM/JS: @mediapipe/tasks-vision 1.0.1 (Apache-2.0), copied from the installed package's wasm directory.
Model: Google MediaPipe selfie_segmenter, float16, downloaded 2026-09-15.
https://storage.googleapis.com/mediapipe-models/image_segmenter/selfie_segmenter/float16/latest/selfie_segmenter.tflite
https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter

All inference is local to the browser. Images are not uploaded. Keep runtime assets aligned with the tasks-vision package when upgrading.
