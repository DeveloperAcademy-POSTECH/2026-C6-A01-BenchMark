# ARTest 원본 촬영 기능 통합

2026-10-11 사용자 요청에 따라 축소한 카메라 UI 대신 `project/ARTest/ARTest`의 현재 Swift 코드를 이식했다. 이슈 #58은 세션·모델·조명 기반, #59는 원본 촬영 UI·사진·영상·조절·애니메이션을 담당한다. PR #60 → #61 순서로 통합한다.

## 원본에서 이식한 기반 기능

- 수평 바닥 raycast 배치, 모델 높이 정규화·발바닥 정렬, 위치 잠금·재배치
- 썸네일 캐릭터 선택: 넙죽이, 포닉스, 대결 모델, 도니, 애니메이션 넙죽이
- 애니메이션 메뉴의 동작 선택·일시정지·재개
- 세로/가로 대응 카메라 미리보기와 하단 촬영 도크
- 배치는 현재 핀치로 크기, 한 손가락 드래그로 회전·바닥 높이를 조절한다. 배치 패널은 제거했다.
- 조명 패널: 환경 밝기 보정, 수동 보조 광원 강도·방위·고도
- 자동 환경 프로브 조명, 접지 그림자, 기기 지원에 따른 사람·공간 가림
- AR 스냅샷 JPG와 촬영 설정 JSON 로컬 저장·공유, 사진 보관함 추가
- ReplayKit 영상·마이크 녹화, 카메라 영역 추출, MP4 결과 재생·저장·공유
- 녹화 방향 잠금·백그라운드/세션 중단 대응

## 앱 통합을 위해 달라진 부분

- 오이기부의 기존 `ARView` 이름 및 다른 기능과 충돌하지 않도록 타입에 AR 접두사를 붙이고 RealityKit.ARView를 명시했다.
- 별도 @main MyApp은 가져오지 않고 OiDonationApp에 원본의 방향 관리 delegate를 연결했다.
- 기존 카메라 버튼의 fullScreenCover 안에 원본 ARCameraScreen을 표시한다.
- 닫기 버튼과 종료 시 세션·로딩·애니메이션 정리를 추가했다. 촬영/녹화 처리 중 닫기를 막고 녹화 중에는 버튼도 숨긴다.
- 카메라 권한 안내의 앱 이름을 오이기부로 변경했다. 기존 앱의 배포 대상·Bundle ID·공유 개발 팀은 유지한다.

모델·썸네일은 사용자 제공 원본이다. 별도 권리 허가를 의미하지 않는다. 가장 큰 모델은 약 61MB이며 전체 모델 약 132MB로 로딩·메모리와 앱 용량은 실제 아이폰에서 확인해야 한다.

## 조절 패널 표시 변경

조절 패널은 카메라 미리보기 위에 ultraThinMaterial로 겹쳐 표시한다. 패널을 열면 촬영 도크가 화면 아래로 내려가며 숨겨지고, 패널이 전체 화면 하단에 표시된다. 접기 버튼으로 닫으면 촬영 도크가 복귀한다. 도크의 레이아웃 공간은 유지하므로 패널 열기/닫기가 AR 뷰포트 크기를 바꾸지 않는다. 세로는 하단 중앙, 가로는 하단 왼쪽에 표시하고 작은 높이에서는 패널 내부를 스크롤한다. 패널 밖 터치는 기존 바닥 배치에 사용한다.


## 사진 설정 (2026-10-11)

- 기본 세로 뷰포트는 3:4, 정사각형 1:1과 세로 9:16도 선택 가능하다. UI 표기는 카메라 관례에 따라 4:3, 1:1, 16:9다. 가로 방향에서는 반전한다.
- 상단 사진 설정 버튼과 반투명 하단 패널을 추가했다. 패널 열기/닫기는 촬영 영역을 변경하지 않는다.
- 타이머 끔/3초/10초. 화면 중앙 카운트다운과 셔터 재탭 취소를 지원한다. 화면 크기/비율 변경, 앱 비활성화, 카메라 종료 시 취소한다.
- 노출은 ARKit의 configurableCaptureDeviceForPrimaryCamera에 실제 노출 보정값을 적용한다. 지원하지 않는 기기는 슬라이더를 비활성화한다. 기존 캐릭터 조명의 exposure와 별개다.
- 필터는 원본/선명/차분/흑백의 채도 처리다. 미리보기는 SwiftUI saturation, 저장은 동일 채도값을 Core Image colorControls로 적용한다. 두 렌더링 경로의 색 공간에 따른 미세한 차이는 실기기 확인이 필요하다.
- 카메라와 AR은 전체 화면에 연속해서 렌더링하며 촬영 비율 밖에는 블러 없이 옅은 검정 오버레이만 표시한다. 저장은 전체 ARView.snapshot에서 화면의 실제 촬영 창 좌표를 픽셀 좌표로 변환해 크롭하여 미리보기 구도를 유지한다. 설정 패널·아이콘·타이머 오버레이는 저장 사진에 포함되지 않는다.
- 시뮬레이터 빌드와 설정 UI 확인 완료. 실제 카메라 노출, 타이머 촬영, 비율별 저장 사진과 미리보기 비교는 실제 iPhone에서 검증해야 한다.

사진 설정의 ‘촬영 영역 밖 배경을 검정색으로’ 토글로 비율 밖 영역을 옅은 검정 오버레이(기본) 또는 완전 검정색으로 전환한다. 사진 저장 영역과 구도에는 영향을 주지 않는다.

캐릭터 크기는 AR 화면의 두 손가락 핀치로 조절한다(0.2~2.5m). 크기 슬라이더는 안내 문구로 대체하며 VoiceOver 조절 동작과 기본값 복원은 유지한다. 위치 잠금은 이동만 막으므로 핀치는 허용한다. 로딩·사진 촬영·녹화 중에는 핀치를 차단하며 바닥 배치 탭은 핀치 실패 후에만 인식한다. 실제 핀치 동작은 iPhone에서 확인해야 한다.

캐릭터를 한 손가락으로 직접 누르고 드래그하면 좌우는 Y축 회전(0.5도/포인트), 위아래는 바닥 기준 높이(-0.3~0.3m, 0.002m/포인트)를 변경한다. 모델에 충돌 형상을 생성해 드래그 시작점이 캐릭터에 해당하는지 검사한다. 위치 잠금 중에도 회전·높이 조절은 가능하다. 두 손가락 핀치 및 바닥 탭 재배치와 구분하며 로딩·촬영·녹화 중에는 차단한다. 실기기에서 캐릭터 터치 판정과 동작 확인이 필요하다.

하단 조절 버튼은 ‘조명’으로 변경하고 패널의 배치 탭과 배치 슬라이더를 제거했다. 패널은 조명만 표시하며 배치는 핀치·드래그·바닥 탭으로 조절한다.

상단 버튼은 같은 행에서 중앙 정렬하고 타이머·비율·필터 모두 사진 설정 패널을 연다. 상태 표시줄은 카메라에서 숨긴다. 카메라 배경은 안전 영역까지 확장하며 하단 버튼의 별도 카드 배경은 제거했다. 배경 검정 토글은 사진 패널과 하단 설정 양쪽에서 같은 값을 변경한다.
