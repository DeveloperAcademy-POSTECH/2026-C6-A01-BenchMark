# AR 캐릭터 카메라 통합

2026-10-11 이슈 #58: ARTest에서 AR 세션·캐릭터 정규화·조명·가림 코드를 이식했다. 기존 RootTabView의 카메라 버튼이 ARView를 전체 화면으로 연다.

- 넙죽이, 포닉스, 대결 모델, 도니, 애니메이션 넙죽이 USDZ 원본 및 썸네일을 재사용한다. 사용자 제공 에셋이며 별도 권리 허가를 의미하지 않는다.
- 바닥 인식 후 터치로 배치·재배치, 위치 잠금, 키·회전 조절을 제공한다.
- 자동 환경 조명과 접지 그림자가 기본이다. 실제 태양 방향 추정이나 실측 그림자를 보장하지 않는다. 지원 기기에만 사람 깊이 가림을 활성화한다.
- 카메라 권한, 시뮬레이터·미지원 안내, 세션 중단·백그라운드 일시정지, 닫기 시 로딩 취소를 처리한다.
- 가장 큰 모델은 약 61MB이므로 초기 로딩·메모리 품질은 실제 아이폰에서 확인해야 한다.

검증: iOS Simulator Debug 서명 제외 빌드 통과. 실제 AR 촬영은 시뮬레이터에서 검증할 수 없다.

## 실기기 확인

- [ ] 권한 허용·거부·설정에서 재허용 후 재시도
- [ ] 각 모델 로딩·빠른 교체·닫기 후 재진입
- [ ] 바닥 인식 전후 배치, 위치 잠금, 크기·회전
- [ ] 실내·그늘·직사광선에서 환경 조명과 접지 그림자
- [ ] 지원·미지원 기기의 사람 가림
- [ ] 백그라운드 복귀·AR 세션 중단

## 사진 촬영 — 이슈 #59

ARTest의 스냅샷 서비스를 연결했다. 배치·모델 로딩·세션 준비 상태를 확인한 뒤 촬영하며 처리 중 중복 촬영과 재배치를 막는다. 사진과 촬영 메타데이터는 앱 Documents/Experiments에 로컬 저장한다. 결과 화면에서 사용자가 요청할 때만 사진 보관함 추가 권한을 요청한다. 사진 공유는 JPG만 내보내며 JSON은 자동 공유하지 않는다. 서버 업로드·동영상은 없다.

스냅샷에는 AR 뷰만 포함되며 하단 UI는 제외된다. 기본 카메라의 고해상도 원본 촬영이 아니다. 메타데이터는 요청 직전 샘플로 사진과 엄밀히 동기화되지 않는다.

- [ ] 실제 아이폰에서 인물과 캐릭터가 함께 사진에 포함되는지 확인
- [ ] 촬영 처리 중 중복 터치·닫기·백그라운드 이동
- [ ] 저장 권한 거부·재허용, 중복 저장 방지·공유
- [ ] 저장 공간 부족과 반복 촬영 시 로컬 저장 용량

검증: 두 브랜치의 iOS Simulator 빌드 통과. 앱 번들에 USDZ 5개와 카메라·사진 추가 권한 문구 포함 확인. 시뮬레이터에서 홈 카메라 버튼 진입·미지원 안내·촬영 버튼 비활성화·닫기 확인. 실제 사진 촬영·저장·조명은 위 실기기 항목이 아직 미검증이다.
