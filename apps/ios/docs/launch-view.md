# 시작 화면

Figma 1308:2327 섹션의 958:4279(문구) → 979:4333(로고) → 1021:4493(홈) 프로토타입을 반영했다.

- 원본 그라데이션·글자·로고 SVG를 로컬 PNG로 3배 해상도 렌더링해 사용한다. 화면 전체 스크린샷을 코드 자산으로 사용하지 않는다.
- 첫 문구 0.5초 유지 → 글자 이동·축소와 다른 글자 페이드, 로고 등장 0.8초 ease-out → 로고 0.3초 유지 → 홈으로 0.8초 dissolve.
- 402×874 디자인 좌표를 화면 중앙에서 비율 유지 확대/축소한다. 배경은 화면 끝까지 확장한다.
- 앱 프로세스 시작 때 한 번 실행하며 탭 이동이나 백그라운드 복귀에는 반복하지 않는다. 시작 화면 동안 홈 입력과 접근성 포커스를 차단한다.
- Reduce Motion에서는 글자 이동을 생략한다. 뷰 제거 시 task 취소를 처리한다.
- Debug 전용 -splash-preview-start / -splash-preview-logo 실행 인자로 각 정지 화면을 시뮬레이터에서 비교할 수 있다. 일반 실행에는 영향을 주지 않는다.

Simulator 빌드, 두 정지 화면의 자산/배치 비교와 일반 실행의 홈 진입을 검증했다. 시스템 Launch Screen은 별도이며 이 화면은 앱 실행 후 SwiftUI로 재생된다.
