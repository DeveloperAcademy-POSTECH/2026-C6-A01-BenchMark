## 카드 스와이프 (1264:4379)

목록 보기에서 한 기부의 사진→이야기→위치 지도 면을 왼쪽 스와이프로 전환한다. 오른쪽 스와이프는 이전 면으로 이동하며 처음/마지막에서 순환하지 않는다. 하단 페이지 점으로도 직접 이동 가능하다. 격자 보기의 기존 뒤집기 동작은 유지한다. 앱 전체 가로 페이징을 제거해 탭 이동은 하단 탭 버튼으로만 한다. 카드 영역에서 시작하는 한 손가락 UIKit pan이 가로 속도가 세로의 1.3배 이상일 때만 시작하고, 가로 이동이 45pt 이상이면 면을 변경한다. 세로 스크롤과 동시에 인식하도록 설정한다. Simulator 빌드 및 좌우 스와이프 전환·세로 스크롤 확인 완료.

탭바는 시스템 Liquid Glass로 바꾸고 흰 바탕을 제거했으며 하단 안전 영역까지 콘텐츠를 확장했다. 마지막 항목을 탭바 위로 스크롤할 수 있도록 contentMargins를 유지한다.
