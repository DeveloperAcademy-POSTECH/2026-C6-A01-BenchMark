# AR 마스코트 선택·손바닥 배치 — #438

2026-11-17 사용자 요청. 이전 로컬 #413·#417 변경 위에서 `feat/#438-ar-mascot-palm`을 만들었다. 서버·초안·공개 외형은 수정하지 않는다.

## 사용 방법

1. 지도에서 공개 오이의 요약 → 오른쪽 위 **3D**로 촬영 화면을 연다.
2. 사진·비디오 토글 왼쪽 버튼에는 현재 캐릭터 하나만 표시한다. 새 촬영 기본값은 **포닉스**다. 포닉스·넙죽이·포닉스 vs 넙죽이와 공룡 잠옷·고양이 잠옷·야구복·농부·운동복 오이를 고를 수 있다. 도니·넙죽이 애니메이션은 선택 목록에서 제외하고 이전 촬영 JSON의 값은 계속 읽을 수 있게 둔다.
3. 오른쪽 배치 메뉴에서 **바닥에 놓기 / 손바닥에 놓기**를 고른다. 바닥은 인식된 수평면을 탭하며 손바닥은 후면 카메라에 손 전체를 보여주면 자동 배치한다.
4. 핀치로 크기를 조절하고 캐릭터를 한 손가락으로 드래그해 위치를 옮긴다. 손바닥 크기는 기본 6.5cm·2.5~20cm, 바닥은 기존 20cm~2.5m 범위다. 손 위 보정은 기준 위치에서 15cm까지다. 손가락 수가 바뀌면 진행 중인 단일 드래그를 초기화한다.
5. 잠금은 현재 공간 위치를 고정하고 손 인식을 멈춘다. 잠금을 풀면 새 손 관찰을 기다린다. 원래 오이는 캐릭터 목록의 **지도 오이**에서 복원한다. 지도 오이의 GPS 배치는 마스코트처럼 드래그로 이동시키지 않는다.

기존 사진/영상·조명·타이머·복구 기능과 공개 오이 재조회는 유지한다. 원래 오이의 촬영 설정과 마스코트 설정을 런타임에서 분리하며, 새 palm 설정은 optional이어서 이전 촬영 JSON도 복원한다.

2026-11-17 목록 후속 변경: 오이 5종은 기존 `Wardrobe` USDZ와 `WardrobeThumbnails` PNG를 재사용한다. 선택한 의상만 기존 `OiWardrobeAsset.loadForPlacement`로 조립하고 AR의 1m 기준으로 정규화한다. 버튼은 캐시된 2D 썸네일을 사용하며 별도 3D 렌더러를 만들지 않는다. 지도 오이 버튼은 공개 상태·배치를 재확인한 승인 초상 이미지를 사용하고, 이미지가 없으면 잎 아이콘을 표시한다.

## Unity 구현 재사용과 범위

로컬 독립 프로젝트 `OiUnityARTest/Assets/Plugins/iOS/OiPalmVision.mm`과 `Assets/Scripts/OiPalmTracker.cs`, `OiPalmGeometry.cs`를 확인했다. iOS 손 인식은 Unity 엔진이 아니라 Apple의 `VNDetectHumanHandPoseRequest`였다. 기존 Swift 실험 `oi-ar-palm-lighting`의 이미지 시각 투영·손 소실 처리도 참고했다. Unity 런타임·두 번째 카메라·새 ML 모델·손 영상 외부 전송을 추가하지 않는다.

- 기존 ARSession의 YCbCr 영상에서 밝기 평면만 CPU로 640px 이하로 축소한다. Core Image GPU 변환·GPU readback·Unity용 BGRA 재확장·메시지는 사용하지 않는다.
- 단일 손, 단일 worker, 동시 이미지 1장으로 제한한다. Vision request와 회색 버퍼를 재사용한다. 기본 최대 12Hz, 저전력 6Hz, serious 4Hz, critical 2Hz다. 실제 빈도는 카메라 프레임 간격·분석 시간에 따라 낮아진다.
- 모드·뷰포트·앱/화면 상태·잠금 변화는 작업 세대를 무효화한다. 이전 작업이 끝나기 전에 새 이미지를 큐에 넣지 않고, 늦은 결과도 적용하지 않는다. ARFrame 전체 대신 처리 중인 pixel buffer 하나와 값 타입의 촬영 시각 카메라 자세·투영을 보관한다.
- Vision의 방향 보정을 되돌린 sensor UV에 ARKit displayTransform을 적용한다. 화면과 같은 촬영 시각의 투영/자세를 사용하며 오래된 2D 점을 새 카메라 자세로 재투영하지 않는다.
- 손목·MCP의 Unity 가중 중심을 사용한다. 손목과 신뢰 가능한 MCP 두 개 이상이면 일부 가림을 허용한다. MCP 폭 7cm·손목 길이 7.5cm를 가정해 깊이를 추정하므로 정밀 손 메시·손바닥/손등 분류가 아니다. 깊이 범위는 15cm~1.5m다.
- 0.35초 이상 새 관찰이 없으면 촬영 가능 상태를 해제한다. 마지막 위치는 최대 0.9초까지 유지한 뒤 숨기고 재획득에서 보간 기준을 초기화한다. 프레임 사이에는 월드 목표점만 평활화한다.
- 마스코트는 지원 목록의 기본 해상도 이하인 30fps 카메라 형식을 선택하고 불필요한 motion blur·depth of field·camera grain을 끈다. 이는 RealityKit 전체 렌더 FPS를 30으로 고정한다는 뜻은 아니다. 손바닥에서는 평면 탐색·환경 반사 갱신·사람/메시 가림을 중단한다. 바닥 메시 재구성은 공간 가림을 사용할 때만 켠다.
- 상세 모델 전체의 convex 충돌 메시 대신 정규화된 경계 상자 하나로 제스처 적중을 처리한다. 보이는 모델·텍스처는 교체하지 않는다. 결과창·화면 이탈은 #417의 렌더러 분리를 유지한다.

공식 API 근거: [Vision 손 관절 인식](https://developer.apple.com/documentation/vision/vndetecthumanhandposerequest), [ARKit 지원 카메라 형식](https://developer.apple.com/documentation/arkit/arconfiguration/supportedvideoformats), [비디오 형식의 프레임 속도](https://developer.apple.com/documentation/arkit/arconfiguration/videoformat-swift.class/framespersecond).
