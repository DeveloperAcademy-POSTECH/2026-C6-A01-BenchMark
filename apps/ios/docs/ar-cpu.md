# AR CPU 조사와 후속 정리 — 2026-11-17 #438

캐릭터 외형과 손 인식 반응을 유지하는 범위에서 조사했다. 자산·텍스처는 [직전 경량화](ar-lightweight.md)의 것을 그대로 사용한다.

## 확인한 원인과 변경

Jun iPhone(iPhone 17, iOS 26.7.3), Release에서 Time Profiler + Activity Monitor로 조사했다. 손 인식을 잠근 고정 모델에서도 앱 CPU가 약 46%였고, 앱의 `session(_:didUpdate:)`보다 ARKit/RealityKit의 공간 추적·프레임 처리 스택이 주된 비용이었다. 후속 비교의 표시 구간(0~42초) 실행 표본 self weight는 AppleCV3D 21.9%, CoreRE 20.8%였다. 이는 표본 내 비중이며 CPU 사용률·전력 비율이 아니다. `Scene.subscribe`/Combine 스택도 앱이 추가한 매 프레임 구독이 아니라 `ARView.commonRenderCallback`으로 이어지는 프레임워크 내부 경로였다.

- 정적 촬영 프리셋 8종만 `ModelEntity(contentsOf:)`로 읽어 계층을 로드 시 합친다. 사용자 승인 오이·애니메이션 모델은 기존 `Entity` 로더를 유지한다.
- 공유 AR 세션을 사용하지 않는 촬영 모델 계층의 `synchronization`을 제거한다. 포닉스 비교에서 엔티티 6→4개, 동기화 구성 6→0개, 모델은 1개로 유지됐다. 이 구성 수 감소를 CPU 감소량으로 환산하지 않는다.
- UI가 읽지 않는 손 위치 필터·프레임 시각·오프셋·실패 플래그를 Observation 추적에서 제외한다. UI용 추적 상태·안내 메시지 갱신은 유지한다.
- 동일 위치·활성 상태·크기·회전·바닥 높이를 엔티티에 반복 적용하지 않는다. 위치 비교는 **정확한 값의 동일 여부**만 사용한다. 작은 손 움직임을 생략하는 임계값은 없다.

카메라 형식(30fps), Vision 최대 12Hz/640px/단일 작업, 열·저전력 제한, 좌표 변환, 손 관절 기준과 깊이·위치 보정·재인식 시한은 바꾸지 않았다. 렌더 해상도·색상·조명·그림자 표현·모델 파일도 바꾸지 않았다. 비공개 FPS API는 사용하지 않았다.

[Apple의 RealityKit CPU 지침](https://developer.apple.com/documentation/realitykit/reducing-cpu-utilization-in-your-realitykit-app)의 정적 계층 평탄화·불필요한 동기화 제거 범위에서 정리했다.

## 동일 자산 전후 비교

21:10 KST, 포닉스 경량 자산 하나를 동일한 카메라·광원·손바닥 모드 고정 위치(높이 25cm, 전방 65cm)에 표시했다. 진단 빌드 안에서 이전 로더와 새 로더를 번갈아 적용했다. 각 전환 뒤 2초·끝 1초를 제외했다. trace가 시작되기 전 구간은 포함하지 않았다. 여기서는 로더 변경을 비교하며 손 추적 중 Observation/동일값 적용 생략 효과를 별도로 측정한 것은 아니다.

| 이전 1 | 5.397초 | 46.36% |
| 정리 1 | 9.285초 | 45.25% |

관찰 시간 가중 평균은 **46.21%→46.15%**로 유의미한 CPU 감소를 확인하지 못했다. 첫 정리 구간의 감소만 선택해 개선을 주장하지 않는다. 두 구간 모두 열 상태는 Nominal이었으나 장시간 발열·배터리·실제 손 추적 지연을 검증한 결과는 아니다. ARKit 공간 추적과 RealityKit 렌더 자체의 비용은 남는다.

원시 자료는 로컬 `/private/tmp/oi-ar-cpu/cpu.trace`, `compare.trace`, `compare-events.jsonl`, `compare-summary.json`, `compare-stacks.txt`에 있다. 사용자 영상·손 이미지·위치 좌표를 기록하지 않았다. 비교 빌드의 진입점·구성 로그·기준 로더는 일반 앱에서 제거했다.

## 검증과 기기 반영

- iOS 27.2 Simulator의 `CPU.xcresult` 5개 검사 통과: 마스코트 3종·의상 5종 로드/정규화, 마스코트 평탄화 전후 가로·깊이 비율, 회전 상태 제한, 손바닥 세션 옵션, 중단 시 렌더러 분리/복귀.
- 손바닥 계산·동시 작업 제한·지연 결과 폐기 및 카메라 수명 주기 Swift 검사 통과.
- 최종 일반 Release 빌드·서명 검증 통과, Jun iPhone 설치/실행 URL과 실제 실행 프로세스 확인.
- 개인 서명 설정은 보존하고 커밋에서 제외한다. 실제 손을 움직인 반응 비교와 장시간 발열 검사는 이번 검증 범위에 포함하지 않는다.
