# 공유 웹 서체

BenchMark 확정 웹 브랜치 `feat/#38-main-concepts`에서 원본 파일을 재사용한다.

- Griun OMIRI: https://www.griun.co.kr/fonts/omiri . 원본 제공자의 전체 사용범위 자유, 폰트 개작·수정·판매 금지 안내에 따라 파일을 수정하지 않는다. 기존 확인일 2026-09-27.
- Pretendard Variable: 원본 파일과 `Pretendard-LICENSE.txt`를 함께 포함한다.

웹 제목에는 Griun OMIRI, 본문·입력·버튼에는 Pretendard를 사용한다. 오이기부 서비스와 BenchMark 팀 페이지의 브랜드 분위기를 공유하며, 페이지 우선순위와 운영 도메인을 확정하지 않는다.
